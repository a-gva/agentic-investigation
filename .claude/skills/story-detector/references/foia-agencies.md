# FOIA Agencies

Common targets for lobbying investigation follow-ups:

| Agency | Typical request |
|--------|-----------------|
| Senate Secretary | LDA filing amendments, correspondence |
| House Clerk | Lobbying disclosure supporting documents |
| DOJ | FARA enforcement records |
| FEC | Contribution records beyond LDA LD-203 |

FOIA requests are generated in story briefs when `missing_pieces` require non-public documents.
