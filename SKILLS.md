# Legislative Investigator

## Skills

Skills live in [`.claude/skills/`](.claude/skills/) (Cursor's skill directory).
[`skills/`](skills/) is a symlink to `.claude/skills/` for challenge submission layout.

Load and follow the relevant skill before starting any task:

- ETL / data ingestion → `.claude/skills/legislative-etl/SKILL.md`
- Entity resolution / cross-chamber linking → `.claude/skills/entity-resolver/SKILL.md`
- Risk scoring / embeddings → `.claude/skills/risk-classifier/SKILL.md`
- Story detection → `.claude/skills/story-detector/SKILL.md`
- Running the full pipeline → `.claude/skills/subagent-orchestrator/SKILL.md`
